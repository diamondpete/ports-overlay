Build offline and integrate with FreeBSD:
 - read the bundled dependency archives from the port-staged ${WRKSRC}/_dist
   (no network); brotli, zstd and zlib are unbundled and taken from the ports
   tree / base system via CMAKE_PREFIX_PATH instead of the vendored copies;
 - add C++ runtime (-lc++) to the curl link on *BSD (BoringSSL is C++; upstream
   only handles Linux);
 - inject OpenSSL:: imported targets into the curl subproject (FindOpenSSL does
   not create them for a static BoringSSL on FreeBSD);
 - install curl headers under include/curl-impersonate to coexist with curl.
